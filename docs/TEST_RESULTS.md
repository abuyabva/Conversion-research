## Ручная проверка Windows / Docker / Ollama

Модель `qwen2.5:3b`, CPU, контекст 4096, PostgreSQL. Проверены реальный HTTP-ответ модели, вызов `describe_metrics`, текущая воронка и `compare_segments(device_source)`. Результаты инструментов совпали с контрольными значениями.

Обнаружен дефект свободного ответа: модель приписала падение desktop-сегментам, хотя инструмент показывал падение только mobile/paid. Исправление: серверный отчёт из результатов инструментов вместо свободного текста модели.

После исправления получен отчёт по двум периодам: 2800/1120 → 2800/910, конверсия 40% → 32,5%. Сравнение сегментов в этом запуске модель не запросила. Поэтому данный запуск подтверждает отчёт по воронке, но не полноту исследования сегментов.

## Что не подтверждено

- Надёжность выбора инструментов по всем 15 ручным вопросам.
- Скорость и отсутствие тайм-аутов на разных устройствах.
- Работа всех OpenAI-совместимых провайдеров.
- Пользовательское исследование и измеримый бизнес-эффект.
- Готовность к публичной эксплуатации.
