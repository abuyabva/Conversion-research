# План пользовательской проверки

Статус: не проведена. Цель — проверить, понимает ли пользователь различие между полученным расчётом, неполным исследованием и неподтверждённой причиной.

Сценарии: выбрать периоды; сравнить общую конверсию; запросить пересечение устройства и источника; найти источник числа в журнале; восстановиться после запроса без дат.

Для каждой сессии фиксировать обезличенный идентификатор участника, выполненную задачу, затруднение, предложенное изменение и результат повторной проверки. Отдельно проверить, не воспринимается ли статус complete как гарантия полноты ответа.
