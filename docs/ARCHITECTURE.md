# Архитектура и решения

Браузер отправляет POST /api/chat. Agent проверяет подтверждённые даты, передаёт вопрос модели и исполняет цикл function calling. ToolRunner разрешает только три операции. IAnalytics выбирает PostgreSQL или встроенный синтетический источник. EvidenceReport формирует наблюдения из успешных ToolTrace.

| Решение | Причина и компромисс |
|---|---|
| SQL считает количества, C# — проценты | Формулы воспроизводимы, модель не выполняет арифметику |
| Фиксированные инструменты вместо SQL от модели | Небольшая поверхность ошибок; новые метрики требуют кода |
| Детерминированный фактический отчёт | Исправляет ошибочное сопоставление сегментов в тексте LLM; свободные объяснения исключены |
| LLM выбирает инструменты | Сохраняется агентный сценарий, но возможны пропущенные разрезы |
| Отдельный Demo | Воспроизводимая демонстрация без внешнего API; не интерпретирует вопрос |
| C# console test runner | Минимум зависимостей; не отображается как xUnit в Test Explorer |
| Минимальный JavaScript | Отправка формы и отображение ответа без сборщика frontend |

## HTTP API

- GET /api/info: режим, источник, периоды набора, тайм-аут исследования.
- GET /api/health: пробный запрос к данным; 503 при недоступности источника. Не проверяет LLM.
- POST /api/chat: JSON с question, start, end, baselineStart, baselineEnd. Пример — example-request.json.

`complete` — модель завершила цикл после хотя бы одного успешного аналитического инструмента. Полнота ответа по смыслу вопроса не проверяется. `partial` — есть ошибки инструментов или сохранённые результаты после тайм-аута одного обращения к модели. `insufficient_evidence` — нет успешного аналитического инструмента. Другие статусы: clarification, invalid_request, model_error, tool_error, limit_reached. Общий дедлайн возвращает HTTP 504; лимит частоты — HTTP 429.

## Данные

Таблицы пользователей, событий и заказов инициализируются db/init.sql. Устройства: desktop/mobile, источники: organic/paid. Упорядоченная воронка считает уникальных пользователей: visit → checkout → paid до исключённого конца периода. В наборе один визит на пользователя.

HTTP к модели разрешён только для loopback и host.docker.internal. Для внешнего адреса нужен HTTPS. Ключ не отдаётся в браузер. Запросы к БД параметризованы; измерения выбираются из списка. Режим read-only сессии не заменяет отдельную ограниченную роль PostgreSQL при публичном размещении.
